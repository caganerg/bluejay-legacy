# 📝 Bluejay

> A minimalist, cloud-based, Markdown-first note-taking application inspired by Obsidian.

Bluejay, notlarınızı bulut üzerinde güvenle saklamanızı ve notlar arasında bağlantılar (`[[wiki-links]]`) kurarak kişisel bir bilgi ağı oluşturmanızı sağlayan minimalist bir not tutma platformudur.

---

## ✨ Özellikler

- 📄 **Markdown Desteği:** Notlarınızı tamamen Markdown formatında yazın ve düzenleyin.
- 🔗 **İç İçe Not Bağlantıları:** `[[Not Adı]]` sözdizimi ile notlar arasında dinamik bağlantılar (backlinks) kurun.
- ☁️ **Bulut Senkronizasyonu:** Tüm verileriniz sunucuda güvenle saklanır.
- 🌙 **Modern & Minimalist Arayüz:** Odaklanmayı artıran karanlık mod (Dark Mode) destekli temiz tasarım.
- 🚀 **Hızlı ve Hafif:** Gereksiz karmaşıklıktan uzak, sadece not tutmaya odaklı mimari.

---

## 🛠️ Teknolojiler (Tech Stack)

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & [shadcn/ui](https://ui.shadcn.com/)
- **Database:** PostgreSQL / Prisma ORM
- **Editor:** Tiptap
